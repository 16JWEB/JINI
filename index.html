SMARTPHONE · ANDROID

스마트폰에서 베트남어 음성 설치

  1. 설정에서 일반 관리 또는 접근성을 엽니다.
  2. 텍스트 음성 변환 또는 글자 읽어주기 메뉴로 이동합니다.
  3. 기본 엔진이 Speech Services by Google인지 확인하고, 옆의 설정 또는 톱니바퀴를 누릅니다.
  4. 음성 데이터 설치에서 베트남어 (Tiếng Việt)를 찾아 다운로드합니다.

기기 제조사와 Android 버전에 따라 메뉴 이름이나 위치가 다를 수 있습니다. 베트남어가 목록에 없으면 음성 엔진을 업데이트한 뒤 다시 확인해 주세요.

WINDOWS

Windows에서 음성 추가

  1. Windows 로고 키 + I를 눌러 설정을 엽니다.
  2. 시간 및 언어에서 음성 또는 음성 입력 메뉴를 엽니다.
  3. 음성 관리에서 음성 추가를 누릅니다.
  4. 목록에서 베트남어 (Tiếng Việt)가 제공되면 선택해 설치합니다.

사용할 수 있는 음성 언어는 Windows 버전과 설치된 음성 기능에 따라 다릅니다. 베트남어가 목록에 표시되지 않으면 해당 Windows 음성 기능에서 지원되지 않을 수 있습니다.

JINI 학습 데이터 보관 안내

1. 기록이 사라질 수 있는 상황

행동위험알아둘 점
새로고침 · 일반적인 사이트 업데이트낮음보통 기존 기록이 유지돼요. 단, 이후 코드 수정으로 저장 형식이 바뀌면 영향이 생길 수 있어요.
홈 화면 아이콘 삭제 · 웹앱 제거 후 재설치주의설치 방식에 따라 데이터가 유지되거나 삭제될 수 있어요. 백업 없이 재설치하지 마세요.
Chrome ↔ 삼성 인터넷 · 카카오톡 브라우저 이동주의브라우저마다 저장 공간이 달라 기록이 안 보일 수 있어요. 자동으로 옮겨지지 않아요.
쿠키·사이트 데이터 삭제 · 해당 사이트 저장공간 초기화높음JINI 학습 기록이 삭제될 수 있어요. 캐시만 지우는 것과 구분하세요.
브라우저 앱 데이터 삭제 · 기기 초기화·교체높음백업이 없다면 학습 기록을 복구하기 어려워요.
시크릿 모드 사용 후 종료높음임시 저장 정보가 세션 종료 시 사라질 수 있어요. 일반 모드에서 학습하세요.

3. 백업 기능이 생기기 전 주의할 점

  1. 공부할 때 되도록 동일한 브라우저와 동일한 JINI 주소를 사용하세요.
  2. 아이콘을 바꾸기 위해 기존 홈 화면 웹앱을 삭제하거나 재설치하지 마세요.
  3. Chrome에서 JINI의 사이트 데이터를 삭제하거나 앱 데이터를 초기화하지 마세요.
  4. 중요한 오픽 답변은 별도로 복사해 두세요. 녹음은 영구 보관되지 않아요.
  5. 사이트 수정 시 기존 저장 키와 기록 형식을 유지하고, 변경이 필요하면 이전 데이터를 읽는 변환 처리를 추가하세요.
